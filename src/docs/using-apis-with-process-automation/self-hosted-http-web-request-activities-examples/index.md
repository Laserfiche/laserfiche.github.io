# Laserfiche Self-Hosted HTTP Web Request Activities examples

{: .note }
**Note:** This section applies to Laserfiche 11 and Laserfiche 12.

HTTP Connectors are a collection of Workflows [HTTP Web Request Activities](https://doc.laserfiche.com/laserfiche.documentation/12/userguide/en-us/content/process-act-http-web-request.htm?tocpath=Laserfiche%20User%20Guide%7CAutomating%20Laserfiche%20Processes%7CAutomating%20with%20Workflow%7CWorkflow%20Activities%20Reference%7CH-R%7CHTTP%20Form%20Post%20and%20HTTP%20Web%20Request%7C_____2) configured to use a specific [Web Service](<https://doc.laserfiche.com/laserfiche.documentation/12/userguide/en-us/content/process-act-web-service-(http-web-request).htm>).
Web Services contains both the credentials and the HTTP base address of the service to connect to.
