# Laserfiche SDK .NET Reference

This reference covers the classes, objects, and methods of the .NET version of Laserfiche's SDK. They are organized into the following namespaces:

- [RepositoryAccess](LfSDKNet104.chm::/html/N_Laserfiche_RepositoryAccess.htm), [RepositoryAccess.Activity](LfSDKNet104.chm::/html/N_Laserfiche_RepositoryAccess_Activity.htm), [RepositoryAccess.Admin](LfSDKNet104.chm::/html/N_Laserfiche_RepositoryAccess_Admin.htm), [RepositoryAccess.Audit](LfSDKNet104.chm::/html/N_Laserfiche_RepositoryAccess_Audit.htm), [RepositoryAccess.Common](LfSDKNet104.chm::/html/N_Laserfiche_RepositoryAccess_Common.htm), [RepositoryAccess.Data](LfSDKNet104.chm::/html/N_Laserfiche_RepositoryAccess_Data.htm), [RepositoryAccess.Linq](LfSDKNet104.chm::/html/N_Laserfiche_RepositoryAccess_Linq.htm), and [RepositoryAccess.Records](LfSDKNet104.chm::/html/N_Laserfiche_RepositoryAccess_Records.htm). These namespaces contain most of the tools you will need to use, except for those relating to document import and export.
- [DocumentServices](LfSDKNet104.chm::/html/N_Laserfiche_DocumentServices.htm) and [DocumentServices.Interfaces](LfSDKNet104.chm::/html/N_Laserfiche_DocumentServices_Interfaces.htm). These contain classes for importing, exporting, OCR, and other actions closely related to document formatting.
- [SecurityTokenService](LfSDKNet104.chm::/html/N_Laserfiche_SecurityTokenService.htm). This is relevant only if you using Laserfiche Directory Server's security token service in your SDK program.
- [I18.n](LfSDKNet104.chm::/html/N_Laserfiche_I18n.htm). This namespace helps with writing international applications, facilitating conversion between different calendars, number formats, time zones, and so on.
- [ClientAutomation](LfSDKClientAutomation104.chm::/html/N_Laserfiche_ClientAutomation.htm). This namespace contains classes for building programs that interact with users' actions in the Laserfiche Windows Client.
