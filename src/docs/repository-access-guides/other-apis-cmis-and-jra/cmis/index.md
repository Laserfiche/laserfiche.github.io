# Getting Started with the Laserfiche CMIS Gateway

The Laserfiche CMIS Gateway allows you to write custom applications to interact with Laserfiche repositories using the [CMIS open standard](http://docs.oasis-open.org/cmis/CMIS/v1.1/errata01/os/CMIS-v1.1-errata01-os-complete.html). Get started by:

- [Installing](./installing-the-cmis-gateway/) and [configuring](./cmis-gateway-configuration/) the gateway
- Learning more about [how CMIS works](./the-laserfiche-cmis-gateway/)
- Viewing [sample web applications](./building-a-cmis-web-application/) that use CMIS to browse, update entries, and create entries in a Laserfiche repository.
- [Troubleshooting](./troubleshooting-the-cmis-gateway/) the gateway

For deeper dives into the details, learn more about:

- The different CMIS bindings supported by the gateway
    - [The AtomPub binding](./the-atompub-binding/) and its [services](./atom-binding-services/)
    - [The browser binding](./the-browser-binding/) and its [services](./browser-binding-and-web-services-binding-services/)
    - [The web services binding](./the-web-services-binding/) and its [services](./browser-binding-and-web-services-binding-services/)
- [Services and object-types](./services-and-object-types/) in CMIS
- [Custom Laserfiche object properties](./laserfiche-object-properties-in-cmis/)
