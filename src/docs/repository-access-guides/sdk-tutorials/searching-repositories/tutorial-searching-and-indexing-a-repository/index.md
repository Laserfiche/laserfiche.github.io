# Searching and Indexing a Repository

In this tutorial, we demonstrate how to index a repository, index specific documents, search a repository, search documents, and turn your search results into an output format of your choice. You must index the documents, folders, or repositories you wish to search before conducting a search on them. For more complex searches, see the section on [advanced search syntax](../search-syntax/).

| Signing in<br>                        <br>We begin by signing in to the repository *myRepo* on the Laserfiche Server *myLFServer*, using the Windows credentials of the current thread. | ```<br>using (Session mySession = new Session())<br>{ <br>    RepositoryRegistration myRepoReg = <br>    new RepositoryRegistration("myLFServer", "myRepo");<br>    mySession.LogIn(myRepoReg);<br>``` |
| --- | --- |
| Indexing a document<br>                        <br>Now we (re)index an existing document *Doc* in the repository. | ```<br>    DocumentInfo myDoc = Document.GetDocumentInfo("\\Doc", mySession);<br>    myDoc.Index();<br>``` |
| Indexing a repository<br>                        <br>Maybe you decided that that was not enough, and want to index the whole repository.  The [IndexAll](LfSDKNet104.chm::/html/T_Laserfiche_RepositoryAccess_IndexOption.htm) option tells Laserfiche to index the whole repository. | ```<br>    IndexConfiguration IC = new IndexConfiguration(mySession);<br>    IC.Reindex(IndexOption.IndexAll);<br>``` |
| Searching a repository and retrieving search statistics<br>                        <br>Now that we've indexed the repository, we can search the whole repository. Here we search for documents containing the word "fish". We then use [SearchStatistics](LfSDKNet104.chm::/html/T_Laserfiche_RepositoryAccess_SearchStatistics.htm) to get the number of documents containing "fish", and print this number to the console. | ```<br>    Search RepoSearch = new Search(mySession);<br>    RepoSearch.Command = "fish";<br>    RepoSearch.Run();<br>    SearchStatistics SS = RepoSearch.GetSummaryStats();<br>    Console.WriteLine("Entries Found: " + SS.DocumentCount);<br>``` |
| Finding IDs of Documents<br>                        <br>If you have information about certain documents but do not know their IDs, you can search using that information and retrieve the IDs of the documents that are hits. Here, we take the previous search results and write their entry IDs and entry names to the console. | ```<br>    SearchListingSettings Settings = new SearchListingSettings();    <br>    SearchResultListing Results = RepoSearch.GetResultListing(Settings);<br>    for (int k = 1; k <= Results.RowsCount; k++)<br>    {<br>        Console.WriteLine(Results.GetDatumAsString(k,<br>        SystemColumn.Id) + " " + Results.GetDatumAsString(k,<br>        SystemColumn.Name));<br>    }<br>    RepoSearch.Close();<br>``` |
| Searching with complex requirements<br>                        <br>Now let's do a more complex search that looks in a particular folder for a certain field value. We will look under the folder "Forms" for documents that have a "Pending" value in their "Approval Status" field, then run the search. | ```<br>    Search FormSearch = new Search(mySession);<br>    FormSearch.Command = @"{LF: LOOKIN = ""\Forms""} &<br>    {[]:[Approval Status] = ""Pending""}";<br>    FormSearch.Run();<br>``` |
| Modifying how search listings appear<br>                        <br>We also want the names of the documents and their last modified dates as part of our search results, and we would like the results sorted by the last modified date. We configure `SearchListingSettings` to display this information. | ```<br>    SearchListingSettings searchSettings = <br>    new SearchListingSettings();<br>    searchSettings.AddColumn(SystemColumn.Name);<br>    searchSettings.AddColumn(SystemColumn.LastModified);<br>    searchSettings.SetSortColumn(SystemColumn.LastModified);<br>``` |
| Using search results to act on documents<br>                        <br>Now we can process the forms search results and modify the document status according to their appearance in the results. To get a list of the results, we pass the `SearchListingSettings` object into the `GetResultListing` method.<br><br>                        <br>We start an empty file "csvText" in preparation for the next section of the code, where we will write the results to a .csv file.<br><br>                        <br>For each result (representing one document that has "Pending" in its "Approval Status" field), we lock the document and change the approval status of that document to "Approved". The end of the `using (EntryInfo...` statement automatically unlocks the document. | ```<br>    using (SearchResultListing listing = <br>    FormSearch.GetResultListing(searchSettings))<br>    {<br>        StringBuilder csvText = new StringBuilder();<br>        csvText.AppendLine("Entry ID, Entry Name, <br>        Last Modified");<br>        foreach (EntryListingRow row in listing)<br>        {<br>            int rowID = (int)row[SystemColumn.Id];<br>            using (EntryInfo eInfo = <br>            Entry.GetEntryInfo(rowID, mySession))<br>            {<br>                eInfo.Lock(LockType.Exclusive);<br>                FieldValueCollection FVC = <br>                eInfo.GetFieldValues();<br>                FVC["Approval Status"] = "Approved";<br>                eInfo.SetFieldValues(FVC);<br>                eInfo.Save();<br>            }<br>``` |
| Writing search results to CSV file<br>                        <br>We are still in the `using (SearchResultListing...` statement at this point. Now we write our search results to a .csv file "results.csv" for reporting purposes.<br><br>                        <br>We also end both the `using (SearchResultListing...` statement and the `using (mySession...` statement. Ending the former helps us avoid hitting the search listing limit---Laserfiche only allows four concurrently open search result listings. Ending the latter automatically signs us out of the repository. | ```<br>            csvText.AppendLine(row.GetDatumAsString<br>            (SystemColumn.Id)) + "," +<br>            row.GetDatumAsString(SystemColumn.Name) + "," +<br>            row.GetDatumAsString(SystemColumn.LastModified));<br>        }<br>        System.IO.File.WriteAllText("results.csv", <br>        csvText.ToString());<br>    }<br>}<br>``` |
