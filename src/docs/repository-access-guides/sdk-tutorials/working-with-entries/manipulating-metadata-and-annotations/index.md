# Manipulating Metadata and Annotations

Here, we present a code sample demonstrating some common actions you can perform on Laserfiche documents' metadata. We show how to create a template, add fields to the template, manipulate field properties, assign a template to a document, manipulate field data, stamp a document, and add a sticky note to a document. See the tutorial on [general entry manipulation](../tutorial-actions-on-documents-and-folders/) for actions not related to metadata.

This code sample uses the RepositoryAccess library.

| Signing in<br>                        <br>Start a session in an existing repository *myRepo* located on an existing Laserfiche Server named *myLFServer*, signing in with the credentials *myUsername* and *myPassword*. | ```<br>using (Session mySession = new Session())<br>{ <br>    RepositoryRegistration myRepoReg = <br>    new RepositoryRegistration("myLFServer", "myRepo");<br>    mySession.LogIn("myUsername", "myPassword", myRepoReg);<br>``` |
| --- | --- |
| Creating a new template and saving it<br>                        <br>Create a new template, assign the existing fields "ID" and "Author" to the template, set the "Author" field to be listed first in the template, and save the template. | ```<br>    TemplateInfo myTemplate = new TemplateInfo();<br>    myTemplate.Session = mySession;<br>    myTemplate.Name = "New Template";<br>    myTemplate.AddField("ID");<br>    myTemplate.AddField("Author");<br>    myTemplate.MoveField("Author", 1);<br>    myTemplate.Save();<br>``` |
| Editing field properties<br>                        <br>Next, we manipulate the "ID" field  as follows. We set the width of the field to be 7 characters, assign it a default value, mark the field as mandatory (meaning every document with the template must have the field filled in), constrain the field value to be of a certain format, configure an error message to be displayed when that format is satisfied, rename the field, and save our changes to the template. | ```<br>    FieldInfo FI = Field.GetInfo("ID", mySession);<br>    FI.ChangeType(FieldType.String);<br>    FI.Length = 7;<br>    FI.DefaultValue = "123-abc";<br>    FI.IsRequired = true;<br>    FI.Constraint = @"\d\d\d-\w\w\w";<br>    FI.ConstraintError = "Invalid format for ID";<br>    FI.Name = "Identifier";<br>    FI.Save();<br>``` |
| Assigning a template to a document<br>                        <br>Assign your new template to an existing document named "Doc". | ```<br>    using (EntryInfo myEntry = <br>    Entry.GetEntryInfo("\\Doc", mySession))<br>    {<br>        DocumentInfo myDoc = myEntry as DocumentInfo;<br>        myEntry.SetTemplate("New Template");<br>        myEntry.Save();<br>``` |
| Adding fields to a document<br>                        <br>With the document `myEntry` still open, edit its field data. Here we add two new fields, with corresponding values, to `myEntry`. Note the two different ways of adding a new field. | ```<br>        FieldValueCollection FVC = myEntry.GetFieldValues();<br>        FVC.Add("myFieldName", "DesiredValue");<br>        FVC["anotherFieldName"] = "anotherDesiredValue";<br>        myEntry.SetFieldValues(FVC);<br>``` |
| Applying a stamp<br>                        <br>Apply a user's private stamp, "Personal Stamp", to the document *myEntry*. We enumerate through the list of the current user's private stamps and apply the stamp that matches the name "Personal Stamp." We also choose the stamp to be red in color, position the stamp to be 200 pixels from the left border and 3000 pixels from the bottom border, and apply the stamp to Page 1 of `myEntry`. To choose a public stamp instead, you would use EnumPublicStamps instead of EnumPersonalStamps. | ```<br>        StampInfoReader ListOfStamps = <br>        Stamp.EnumPersonalStamps(mySession);<br>        foreach (StampInfo SI in ListOfStamps)<br>        { <br>            if (SI.Name == "Personal Stamp")<br>            {<br>                StampAnnotation SA = new StampAnnotation();<br>                SA.StampId = SI.Id;<br>                SA.Color = LfColor.FromAbgr(255); <br>                LfPoint PT = new LfPoint(200, 3000); <br>                SA.Position = PT;<br>                PageInfo PI1 = myDoc.GetPageInfo(1);<br>                PI1.AddAnnotation(SA);<br>            }<br>        }<br>``` |
| Applying a sticky note<br>                        <br>Next, we apply a sticky note that says "This is a brand new sticky note" to the second page of `myEntry`. We attach a comment on the sticky note  and position the sticky note to be 900 pixels from the left and 900 pixels from the bottom. Using the GetPageInfo function, we place the sticky note on the second page of the document. Finally, we save the changes we have made to the document. | ```<br>        NoteAnnotation NA = new NoteAnnotation();<br>        NA.Text = "This is a brand new sticky note";<br>        LfPoint point = new LfPoint();<br>        point.X = 900;<br>        point.Y = 900;<br>        NA.Position = point;<br>        NA.IsPrivate = true;<br>        NA.Comment = "This is a short comment";<br>        NA.KeepHistory = true;<br>        PageInfo PI2 = myDoc.GetPageInfo(2);<br>        PI2.AddAnnotation(NA);<br>        myDoc.Save();<br>    } <br>        <br>    <br>``` |
| Retrieving field values<br>                        <br>Retrieve field values from a document that has a multi-valued field `FieldName`. Print the field value to the console. | ```<br>    using (EntryInfo myEntry = <br>    Entry.GetEntryInfo("\\MultiValueFieldDoc", mySession))<br>    {<br>        object fieldVal = myEntry.GetFieldValue("FieldName");<br><br>        var values = new List<object>();<br>        if (fieldVal != null)<br>        {<br>            var valArray = fieldVal as Array;<br>            if (valArray != null)<br>            {<br>                foreach (object val in valArray)<br>                {<br>                    values.Add(val);<br>                }<br>            }<br>            else<br>                values.Add(fieldVal);<br>        }<br><br>        for (int i =0; i < values.Count; i++)<br>            Console.WriteLine(values[i]);<br>    }<br>``` |
| Retrieving dynamic field values<br>                        <br>Retrieve field values from a document that contains dynamic fields. The existence of dynamic fields is checked using the function HasFormLogicRules. We then store the field information of each dynamic field in the object `fielddata`, write the value of each dynamic field to a temporary string, then show the dynamic field names and values in a message box. The very last `}` closes the repository session that we started at the beginning of this tutorial. | ```<br>    using (EntryInfo myEntry = <br>    Entry.GetEntryInfo("\\DynamicFieldDoc", mySession))<br>    {<br>        FieldValueCollection FVC = myEntry.GetFieldValues();<br>        TemplateInfo myTemp = <br>        Template.GetInfo(myEntry.TemplateName, mySession);<br>        if (myTemp.HasFormLogicRules())<br>        {<br>            FormLogicRuleInfo[] FormLogicRules = <br>            myTemp.GetFormLogicRules();<br>            foreach (FormLogicRuleInfo dynamicField <br>            in FormLogicRules)<br>            {<br>                FieldInfo fielddata = <br>                Field.GetInfo(dynamicField.FieldId, mySession);<br>                Laserfiche.RepositoryAccess.Data.LfDataReader<br>                data = dynamicField.GetDataReader(FVC);<br>                string temp = "";<br>                while (data.Read())<br>                {<br>                    temp = temp + data[0].ToString() + "\n";<br>                }<br>                System.Windows.Forms.MessageBox.Show(<br>                "Available Values For "<br>                + fielddata.Name + ": " + "\n" + temp);<br>            }<br>        }<br>    }<br>}<br>``` |
