# Laserfiche SDK

## Getting Started

Get a quick start on writing your first SDK program with some [short](./getting-started-with-the-sdk/writing-your-first-sdk-program/) [code samples](./getting-started-with-the-sdk/signing-in-to-a-repository/), including a [sample Powershell script](./getting-started-with-the-sdk/powershell-scripting-with-the-sdk/). Learn about [Laserfiche architecture](./getting-started-with-the-sdk/laserfiche-architecture/key-concepts-in-laserfiche-architecture/) if this is your first time working with Laserfiche repositories. We also offer an overview of the [components of the SDK](./getting-started-with-the-sdk/sdk-overview/), along with [installation instructions](./getting-started-with-the-sdk/installing-the-laserfiche-sdk/). If you have a program ready to go, learn how to [distribute your application](./getting-started-with-the-sdk/deploying-laserfiche-sdk-dependencies-for-net-com-applications/) to users. Finally, consult our [FAQ](./getting-started-with-the-sdk/frequently-asked-questions/) for any lingering questions.

## Tutorials

In these tutorials, we show you how to perform common tasks using the .NET components of the SDK. Find out how to [manipulate documents and folders](./sdk-tutorials/working-with-entries/key-concepts-for-working-with-documents-and-folders/), [administer users and security permissions](./sdk-tutorials/users-groups-and-security/key-concepts-for-working-with-users-groups-and-security/), [search repositories](./sdk-tutorials/searching-repositories/key-concepts-for-searching-with-the-sdk/), use the [Laserfiche Query Language](./sdk-tutorials/laserfiche-query-language/constructing-a-laserfiche-query-language-command/) (LFQL), implement [records management](./sdk-tutorials/records-management/key-concepts-for-records-management/), subscribe and retrieve [notifications](./sdk-tutorials/notifications/key-concepts-in-notifications/), access [Laserfiche Cloud](./sdk-tutorials/cloud/using-the-sdk-for-laserfiche-cloud/), and [integrate with users' actions in the Windows Client](./sdk-tutorials/client-automation-tools/key-concepts-for-client-automation/).

The Laserfiche SDK also offers integration using the [Content Management Interoperability Services (CMIS) specification](./other-apis-cmis-and-jra/cmis/the-laserfiche-cmis-gateway/).
