# Laserfiche Process Automation Connectors

## Overview

Laserfiche Process Automation Connectors are a collection of ready to use Rules or Activities that can be used when building Business Processes or Workflows.
Laserfiche Process Automation Connectors in this website are provided under [MIT Licensed](https://github.com/Laserfiche/laserfiche.github.io/blob/1.x/LICENSE-CODE) and can be freely used when building [Laserfiche Process Automation](https://doc.laserfiche.com/laserfiche.documentation/en-us/Default.htm#../Subsystems/ProcessAutomation/Content/Resources/Get-Started.htm?TocPath=Process%2520Automation%257CGetting%2520Started%2520with%2520Process%2520Automation%257C_____0) solutions.
