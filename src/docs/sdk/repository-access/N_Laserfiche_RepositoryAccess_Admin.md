# Laserfiche.RepositoryAccess.Admin Namespace
 

The Laserfiche.RepositoryAccess.Admin namespace contains classes that deal with the administration of a Laserfiche content repository server. Operations that involve configuring the data inside a repository are not implemented by classes in this namespace.
