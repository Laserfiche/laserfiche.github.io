# UserInfo.CanUsePassword Property 
 

Gets or sets a boolean indicating whether or not the user can authenticate to Laserfiche with a password. If this is false, a Windows user account must be linked to the Laserfiche user account and Windows authentication used for the Laserfiche user to log in.
