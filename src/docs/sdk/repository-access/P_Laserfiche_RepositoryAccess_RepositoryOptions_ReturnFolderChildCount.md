# RepositoryOptions.ReturnFolderChildCount Property 
 

Gets or sets a boolean indicating if Laserfiche will calculate the number of browseable folders that are children of each of the folders in a folder listing. Necessary for the plus sign in the folder tree in the Laserfiche client to accurately reflect the folder hierarchy but significantly slows down browsing.
