## Remarks
When the `Server` class is first initialized, it contains a server name but the server's properties are not retrieved until `Refresh` is called. A valid port does not have to be specified to successfully invoke `Refresh`, but setting the correct port before calling `Refresh` can improve performance. The `Server` class is not thread-safe. Multiple threads must synchronize access to instances of the class. One exception to the previous rule is that multiple threads may concurrently read properties, if no methods are being invoked.
