# DocumentExporter.CompressionQuality Property 
 

Gets or sets the compression quality for image types which support a configurable compression level. Ranges from 0 (most compression, lowest image quality) to 100 (least compression, highest image quality). If lossless compression is available, set `CompressionQuality` to 100 to enable it.
