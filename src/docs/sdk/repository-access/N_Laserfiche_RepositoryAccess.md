# Laserfiche.RepositoryAccess Namespace
 

The Laserfiche.RepositoryAccess namespace contains the core classes for accessing Laserfiche. This includes operations like logging in to a repository and configuring, viewing and manipulating the data stored inside a Laserfiche content repository. Helper classes that simplify the job of importing and exporting data can be found in the Laserfiche.DocumentServices assembly.
