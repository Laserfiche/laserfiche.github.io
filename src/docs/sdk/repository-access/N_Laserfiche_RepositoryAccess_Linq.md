# Laserfiche.RepositoryAccess.Linq Namespace
 

The Laserfiche.RepositoryAccess.Linq namespace contains classes which implement a Language Integrated Query (Linq) provider which encapsulates the Laserfiche ADO.NET provider in the Laserfiche.RepositoryAccess.Data namespace. The RepositoryAccess Linq provider generates LFQL queries from Linq expressions and executes them using the Laserfiche ADO.NET provider.
