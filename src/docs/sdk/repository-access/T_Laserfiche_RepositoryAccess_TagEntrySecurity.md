## Remarks
Tag ACLs work differently than other types of object ACLs in Laserfiche. They are used to control which feature rights are present on entries rather than controlling access to tags themselves. Tag ACLs from all the tags assigned to an entry are combined into a single "super ACL" and effective feature rights (not entry access rights) are calculated from this.
